# CLI 与 Web 是同一套能力的两个交互面，不是两个产品

本工程设计的功能（Decision、Prediction、清单与叙事、结算、触达），**一面有的能力，另一面必须有**。差异只允许出现在形态与操作习惯上——CLI 面向 Agent 与脚本（确定性 JSON、一条命令），Web 面向人（并排、颜色、可点击）。形态不同不等于能力缺失。规范条文见 [AGENTS.md](../../AGENTS.md) 第 10 节。

**范围**：只覆盖本工程自己定义的功能面。fork 继承来的旧功能（Slack、Discord、Chrome 扩展、锦标赛、博客）不受此约束——它们本来就只存在于单侧，且多数已被 ADR-0013 排除出 MVP。

**对等单元**：一条 tRPC procedure。只在单侧可达的 procedure 必须**登记为有意例外并写明理由**，不许默认容忍。

## Considered Options

- **每个面各自专精**（Web 承担人机重交互，CLI 只暴露 Agent 真正需要的那一部分）：成本最低，也是最初的实际做法。但它让"能力"取决于你恰好用哪个界面——同一个问题，换个入口就做不成，而人是会用错入口的。
- **只保留 CLI**（删掉 Web）：用户明确否决。删掉 Web 就等于永远违反本规则；而且 ADR-0007 已经把"人类直接操作的写入口"定为最可信的兜底输入源。
- **只保留 Web**：同理否决——Agent 需要确定性 JSON 与"不依赖服务常驻"，这是 ADR-0015 的立论。

## Consequences

- **US20（Web 侧的决策写入口）不再是"待办"，而是违反本规则**。ADR-0007 的要求因此重新生效：人类必须能在界面上创建/编辑/结算，而不是只能通过 CLI。
- CLI 侧要补对等命令：`decision.list` 目前没有 CLI 对等物（只能 `show-decision --decision-id`，前提是已知 id）。
- 每新增一条 procedure，成本从"实现一次"变成"决定要不要在两面都实现，或登记例外"——这是本规则的主要代价，换来的是"换入口就做不成事"不再发生。
- 例外必须是**有理由的登记**，而不是沉默的缺失；登记表就是本 ADR 下面这张。

## 现状例外清单（据实登记）

| 能力                                                                                              | 现状                                                                                                                      | 性质                                                                                                                                                                                         |
| ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| `create-decision` / `set-rubric` / `update-narrative` / `attach-prediction` / `detach-prediction` | 仅 CLI                                                                                                                    | **待补**：Web 侧缺写入口，ADR-0007 要求保留                                                                                                                                                  |

| `tags.getAll`                                                                                     | 仅 Web（`TagsSelect` 候选列表）                                                                                           | **永久例外**：能力已在 Web；对决策领域无 CLI 用途（ADR-0030 §三）                                                                                                                            |
| `tags.getByName`                                                                                  | 仅 Web（题页 `/tag/[tag]`）                                                                                               | **永久例外**：同上                                                                                                                                                                           |

| `tags.renameDomain`                                                                               | 仅 CLI                                                                                                                    | **待补**：改名会重写历史归属（带理由留痕），需要专门的领域整理视图而不是顺手一改的按钮；暂以 CLI 为唯一入口（ADR-0030 §十四）                                                                |

| `agent.listAuditRecords`                                                                          | 仅 CLI                                                                                                                    | **待议**：审计筛选是库主对全库的复查动作（不是单条问题的视图），而审计字段在他人读路径上的可见性尚未裁决（ADR-0027 Consequences 明写“尚未裁决”）                                             |
| Slack / Discord / Chrome 扩展 / 锦标赛 / 博客                                                     | 单侧或未接                                                                                                                | **范围外**：fork 继承功能，不受本规则约束                                                                                                                                                    |
