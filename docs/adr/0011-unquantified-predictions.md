# 允许"未量化的预测"：追问的终点可以是当事人尚未想清楚

当当事人明确表示还没想清楚、或拒绝给出概率时，记录 Agent **只存命题、不存 `Forecast`**（`Q` = ①），既不丢弃，也不进草稿区。该 `Prediction` 保持**未量化**状态：可展示、可复盘，日后可补上概率，但在此之前**不参与校准**。

为什么要有这个终点：追问到底（ADR-0010）若没有终点，就会逼出 `Compliance Number`。而假样本比空样本更毒——它既污染校准曲线，又让人误以为那反映了自己的判断。把"我不知道"设为合法终点，是追问强度的**必要配套**，不是对它的削弱。

为什么不是丢弃：决策陈述本身就有复盘价值——ADR-0001 的"决策质量"评的是**过程**而非概率。更关键的是，它让**"我当初逃避了量化"这件事可见**。逃避被记录下来，逃避才有可能被矫正（Phase 5 主动偏差诊断的输入）。

## Considered Options

- **② 存草稿**：引入第二套状态机；而"未量化的 Prediction"已能表达同一件事。
- **③ 丢弃**：抹掉了最有价值的矫正材料。

## Consequences

- 领域模型必须允许 `Prediction` 有 **0 个** `Forecast`。
- "未量化"是合法且可查询的状态，不是错误态。
- 与 ADR-0008 自洽：没有数字 → 无从背书 → 不进校准。
