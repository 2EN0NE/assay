# 决策捕获在对话中自动识别，察觉即追问

记录 Agent 在对话中**自动察觉**决策（`I` = ③：自动识别为主，用户显式指令兜底），并在察觉后**立即追问**（`P` = ①），而不是静默攒批、稍后收敛。

选择即时追问的理由是**校准数据的保真度**：校准要测的"你的信念"是一个会随时间漂移的量。等到话题告一段落再回头问"刚才那个几成把握"，你给出的是**重构**出来的数字，而不是当时的判断。越贴近原始时刻采集，样本越真实——这与本项目的立身之本（把隐含信念显性化）是同一条线，延迟采集会把"显性化"退化成"事后合理化"。

代价是 Agent 会频繁插话。缓解手段是已定下的"多轮、可打断"（roadmap `J` = ②）：**打断的时机交给我们，但当事人随时可以喊停**。

## Considered Options

- **② 静默收集、停顿处收敛**：不打断心流，但采集到的是事后重构的概率。
- **③ 完全静默**：不打断，且攒下的记录停在"未背书"态，既不进校准也没闭环。

## Consequences

- 记录 Agent **不需要**"会话内候选池"——察觉即追问、追问即落库（或落为未背书）。
- 需要一条"稍后再说"的即时退路，与 roadmap `J` 的"可打断"配套，否则退化为审讯。
- **已知风险**：打断带来的社交压力可能产出"为尽快打发 Agent 而随口给的数字"（敷衍数字），而不是深思熟虑的置信度。缓解手段见 roadmap `J`。
