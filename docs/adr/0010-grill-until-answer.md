# 追问到底：宁可把当事人逼出数字，也不放过

记录 Agent 在察觉决策后，会**追问到拿到概率、期限与判据为止**（`J` = ①），而不是每轮只问一个缺口、拿不到就留白。

这是当事人**主动选择**的。本项目的成立前提就是"人不会主动量化自己的信念"，所以克制追问等于回到起点。当事人同时选择了被打断（ADR-0009 的 `P` = ①）与被追问（本 ADR），本质是把"对抗自身的回避倾向"外包给 Agent——**沉默不是中立，沉默就是没记录**。

代价是 **`Compliance Number`（敷衍数字）**：打断与追问的社交压力会让人给出一个自己从未想过的数。它比沉默更糟——当事人**一旦给出数字即构成背书**（ADR-0008），这个假样本会进入校准。

## Considered Options

- **② 每轮只问一个缺口、拿不到即留白**：对敷衍数字是结构性防御，但等于允许当事人逃避量化。
- **③ 按决策轻重分级**：需要先定义"轻重"，MVP 阶段成本过高。

## Consequences

- 必须定义**追问的终止条件**：什么时候算"到底"？（见 roadmap `Q`）
- 缓解手段**不是"少问"**，而是给"我还没想清楚 / 拒绝回答"一个**显式出口**，并把它记为一条**无概率的预测**，而不是逼出一个假数字。
