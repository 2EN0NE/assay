# 领域评估的判据：相对领域基准率的技能分，且客观优先于便捷

单人场景里"我在 X 领域水平如何"没有参照物：绝对 Brier 不可解释（同一个 0.18，在大概率事件与小概率事件上是相反的评价），而相对分是"相对同期其他预测者中位数"，单人部署下**恒为 `null`**——目标在定义上不可达。多 Owner 场景（ADR-0025）保留那个相对分，本 ADR 补上单人的那一半。

**一、单条题没有"实际概率"。**
一条题结算后的结果是 **0 或 1**。逐条比较"我预测 0.7 与实际 0.7"这件事**不存在**；"实际频率"只在**分桶**之后出现（所有你给过 ~0.7 的题里实际发生了百分之几）——那就是校准曲线。因此判据必须在**同一个领域的多条题**上定义。

**二、判据 = 相对该领域基准率的技能分。**

- 参照物 = **该领域已结算题的实际发生率**（一个常数 `p̄`）："对该领域每条题都押 `p̄`"这个朴素策略也有一份 Brier，记为 `Brier_ref`。
- 技能分 = `1 - Brier / Brier_ref`。为 0 ⇒ 你的判断相对朴素策略**没有任何增值**；为正 ⇒ 有；为负 ⇒ 比朴素策略更差。
- **`p̄` 必须由系统计算**：不接受自报数值、不接受手工配置、不接受按题覆盖。

**三、同时呈现四件读数，但只有技能分带方向。**

| 读数                   | 回答什么                                                     | 性质                 |
| ---------------------- | ------------------------------------------------------------ | -------------------- |
| 样本数 N（含悬空计数） | 这份读数建立在多少条题上                                     | 元信息               |
| 校准（分桶曲线）       | 偏得准不准                                                   | 形状                 |
| 分辨率                 | 概率有没有把结果区分开（"永远押 0.4"的人校准完美但分辨率 0） | 形状                 |
| 技能分                 | 我比"照着基准率押"强吗                                       | **唯一的方向性判据** |

绝对 Brier 仍然显示，但**不作判据**。

**四、样本不足时不显示判据。**
`N < 20` 只显示 N 与悬空计数，不显示曲线与技能分；`N < 5` 连桶也不显示。少样本下技能分的方差大于它包含的信息量——**显示它就是显示噪音**。阈值是代码常量（与 ADR-0020 的条目集合同精神：属于产品语义，不是用户数据），可随经验调整。

**读法（据实澄清）**：本节说的“曲线”指校准曲线的**图形呈现**（既有的 `components/CalibrationChart.tsx`，ChartJS），“桶”指其**数字**（分桶表）。二者是这个仓库里原本就分开的两件呈现物，所以两句话并不冲突：`5 ≤ N < 20` 给桶与分辨率（形状）、不渲染曲线、也不给技能分；`N < 5` 连桶也不给。**阈值卡的是判据（技能分），不是形状**——理由就是上一句的“方差大于信息量”。

**五、客观优先（三条禁令）。**

- 不接受自报基准率——自报的参照物可被优化，等于没有参照物。
- 不提供"手动录入/调整我的水平"。
- 不把过程完成度折算进结果判据（ADR-0002 已分层）。

任何"更便捷"的替代，只要使**判据可被被评者本人影响**，一律拒绝：它省下的那点摩擦，正好是判据失去意义的那个部分。

**六、分母必须透明。**
按 ADR-0031 被悬空的题不进判据，但必须在样本数里显式列出（"N = 24，其中 3 条悬空未计入"）。不透明的分母等于伪造的结论。

## Considered Options

- **绝对 Brier 作判据**：单条即可计算 → 但没有参照物，数字不可解释。
- **owner 相对分作单人判据**：与 ADR-0002 一致 → 但单人部署下恒为 `null`，目标不可达。
- **自报基准率**（每条题自己声明参照）：贴合直觉 → 参照物可被优化，判据形同虚设。
- **只给曲线让你自己看形状**（不给技能分）：最不武断 → 把"这条曲线算好还是坏"的解释责任全部交回用户，等于不回答"我的水平如何"这个问题。

## Consequences

- **查询**：需要"按领域统计已结算题实际发生率"。领域分桶已具备（ADR-0030），此处只是换一个聚合口径。
- **CLI**：一个 `domain-report --domain <名>` 输出四件读数（JSON）。
- **Web**：一个领域页呈现同样四件读数（AGENTS.md §8 的对等要求）。
- **测试**：一条自证用例——**对每条题都押 `p̄` 时技能分必须为 0**（把参照逻辑去掉即变红）；一条证明悬空样本不进判据但进分母。
