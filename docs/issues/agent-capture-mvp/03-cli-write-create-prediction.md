# 03 — CLI 写入：创建命题与预测值

**What to build:** 一条命令写入"命题 + 概率 + 期限 + 判据"，来源标为 agent、默认未背书；概率可省略（"还没想清楚"是合法状态）。

**Blocked by:** 01, 02

**Status:** implemented (验证记录见 `verification.md`；e2e 待浏览器二进制可用后由本地执行)

- [ ] 一条命令可创建命题并（可选）带概率
- [ ] 判据为空或期限缺失时拒绝写入并给出明确报错
- [ ] 写入后 Web UI 可见该命题
- [ ] 未给概率时不创建预测值，且该命题状态标记为"未量化"
- [ ] 单元测试覆盖三种情形（有概率 / 无概率 / 参数非法）
- [ ] e2e 覆盖"CLI 写入 → Web UI 可见"
