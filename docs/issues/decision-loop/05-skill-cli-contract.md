### 关于第二条 AC 的口径

原文是“照抄 skill 示例里的命令落库后 `list-unendorsed` 能看到它（现在是看不到的，与本票据要修的
行为正好相反）”——那句话描述的是**修正前的**默认极性（agent 记的数字被当成当事人说的，于是
背书队列里看不到）。票据 04-provenance 已把默认翻转，而技能现在**每条写入都显式声明来源**，
