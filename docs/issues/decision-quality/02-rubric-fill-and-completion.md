# 02 — 清单在决策当时填写，完成度可查

**What to build:** 决策创建后能逐条记录清单完成情况（做到 / 没做到），并看到"5 项做到 3 项"这样的完成度。清单条目来自 ADR-0016 的五条常量：备选方案 ≥ 2 / 事前剖析 / 参考基准率 / 写下"我可能错在哪" / 判据可证伪且已冻结。

**Blocked by:** 01

**Status:** implemented（验证：`npm run typecheck` / `npm run lint` / `npm test` / `npm run test:e2e` 全部通过；详情页的清单区已由 e2e 实跑，见 ticket 06）

- [x] 五个条目来自代码常量，标识（key）稳定、与展示文案解耦（`RUBRIC_ITEMS`）
- [x] 只能写已知条目的完成情况；未知条目被拒绝（且不写库）
- [x] 每条只取"做到 / 没做到"两值，没有"不适用"（`RubricStatus` 二值）
- [x] 完成度 = 该决策版本内“做到项数 / 条目总数”，且**不读任何结算结果**（推导函数的入参只有清单记录）
- [ ] 清单条目集合删掉一条后，历史决策的记录仍显示当初的条目与其完成情况（界面改为按该决策所属**决策版本**渲染；数据侧已由“按版本计分”保证，缺的是界面那一半）
- [x] 决策详情页显示清单与完成度
